# Moving Without Meltdown Guide

A friend-paced moving manual: an eight-week countdown, an
address-change master list, utility transfer scripts written as actual
phone scripts, mover quotes decoded in plain English, rental
walk-through photo routines, the first-night box, packing by zone, and
a gentle unpack order for people who have a working week to respect.

Everything is written the way a friend would explain it: plain
English, step by step, never condescending — with calm humor in
place-to-place. Built by **Asdale Dynamics, LLC** as one of our
free, local-first life-admin helpers, complementing the
Free Home Inventory Kit and the Free Emergency Binder Kit.

**Privacy in one sentence: nothing here touches the internet.**
No signups, no accounts, no telemetry, no web fonts, no scripts.
You can build and read the whole site with your Wi-Fi off — that's a
feature, not a limitation.

## What's included

| Path            | What it is                                                       |
|-----------------|------------------------------------------------------------------|
| `docs/`         | The manual itself: 11 markdown pages, the source of every web page |
| `assets/`       | One calm stylesheet (no web fonts, no remote anything)            |
| `site/`         | The built static site — regenerated by `build.py`, not hand-edited |
| `build.py`      | Pure-stdlib static site generator: docs/*.md, index, printable checklist page |
| `checklist.html` (built) | The whole eight-week countdown on one printable page     |
| `09-cost-worksheet.html` (built) | Every move-shaped cost on one worksheet          |
| `10-glossary.html` (built) | "LTL," "accessorials," "tariff," and friends, translated |
| `tests/`        | pytest suite: build integrity, privacy guarantees, content checks |
| `GUIDE.md`      | A short friendly tour for first-time readers                      |

## How to run it

Tested on Python 3.13; anything 3.9+ should work. Nothing to install.

```bash
python3 build.py        # builds the site into site/
python3 build.py --check  # then verify every page exists and is local-only
open site/index.html    # or just double-click it
```

Run the test suite with:

```bash
python3 -m pytest tests/ -v
```

## Privacy guarantees (test-enforced)

- The build emits **no remote URLs** of any kind: no `http://` or
  `https://` anywhere in the built site.
- **No scripts**: pages are plain HTML + one stylesheet.
- **No accounts, no analytics, no cookies** — there's nothing to log in to.
- Files contain **no secrets, API keys, or personal data**; every date,
  name, and address field in the docs is a `[placeholder]` for you to
  fill in.
- The pytest suite scans for all of the above so the guarantees can't
  quietly rot.

## The three rules, in case you're in a hurry

1. **Boring beats brilliant.** A small list done tonight beats a
   perfect plan you'll start "this weekend."
2. **Photos on everything.** Meters, walls, sofas, serial numbers.
3. **One box decides the whole day:** the [first-night box](docs/06-first-night-box.md)
   rides with you, never the truck.
